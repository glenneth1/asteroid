* Installation Overview

Asteroid Radio runs entirely as a single SBCL process. The audio streaming server (CL-Streamer) is built into the application — no external Icecast or Liquidsoap services are required. The only external dependency is PostgreSQL for persistent data.

This guide covers both native (local) and Docker-based installation.

#+BEGIN_QUOTE
*Note on Package Managers*: Examples in this guide use =apt= (Debian/Ubuntu). Replace with your distribution's package manager:
- Fedora/RHEL: =dnf= or =yum=
- Arch Linux: =pacman=
- openSUSE: =zypper=
- Alpine: =apk=
#+END_QUOTE

* Quick Start (Native)

** Prerequisites
- *SBCL* — Steel Bank Common Lisp (2.2+)
- *Quicklisp* — with Shirakumo distribution (for Harmony, cl-mixed, Radiance)
- *PostgreSQL* — running instance (native or Docker)
- *GCC* — for compiling the FDK-AAC C shim
- *System libraries* (see below)

** Install System Dependencies (Ubuntu/Debian)
#+BEGIN_SRC bash
# Core build tools
sudo apt install -y sbcl git curl gcc make

# PostgreSQL
sudo apt install -y postgresql postgresql-client

# Audio encoding/decoding libraries (runtime + dev headers)
sudo apt install -y \
  libmp3lame-dev libfdk-aac-dev \
  libflac-dev libmpg123-dev \
  libtag1-dev libfixposix-dev
#+END_SRC

** Build and Run
#+BEGIN_SRC bash
# Clone repository
git clone https://github.com/fade/asteroid.git asteroid-radio
cd asteroid-radio

# Initialize the database (first time only)
sudo -u postgres psql -d asteroid -f docker/init-db.sql

# Build the SBCL image
make

# Run
./asteroid
#+END_SRC

** Verify Installation
#+BEGIN_SRC bash
# Web interface
curl -I http://localhost:8080/

# MP3 stream (served by CL-Streamer on port 8000)
curl -I http://localhost:8000/asteroid.mp3

# AAC stream
curl -I http://localhost:8000/asteroid.aac
#+END_SRC

* Detailed Installation

** System Requirements

*** Native Installation
- *OS*: Ubuntu 22.04+ / Debian 12+ (or any Linux with SBCL support)
- *RAM*: 1GB minimum, 2GB recommended
- *Storage*: 10GB minimum, 100GB+ for music library
- *CPU*: 1 core minimum, 2+ cores recommended
- *Network*: Stable internet connection for streaming

*** Docker Installation
- *OS*: Any OS with Docker support (Linux, macOS, Windows)
- *Docker*: Docker Engine 20.10+ and Docker Compose 2.0+
- *RAM*: 2GB minimum, 4GB recommended
- *Storage*: 20GB minimum, 500GB+ for music library
- *CPU*: 2 cores minimum, 4+ cores recommended

** Native Installation

*** Step 1: System Updates
#+BEGIN_SRC bash
sudo apt update && sudo apt upgrade -y
#+END_SRC

*** Step 2: Install System Dependencies
#+BEGIN_SRC bash
# Core build tools
sudo apt install -y sbcl git curl wget gcc make build-essential

# PostgreSQL
sudo apt install -y postgresql postgresql-client

# Audio encoding libraries (MP3 via LAME, AAC via FDK-AAC)
sudo apt install -y libmp3lame-dev libfdk-aac-dev

# Audio decoding libraries (FLAC, MP3 via cl-mixed backends)
sudo apt install -y libflac-dev libmpg123-dev

# Audio metadata extraction (taglib)
sudo apt install -y libtag1-dev

# Networking (required by iolib for socket operations)
sudo apt install -y libfixposix-dev
#+END_SRC

*** Step 3: Install Quicklisp
#+BEGIN_SRC bash
# Download and install Quicklisp
cd /tmp
curl -O https://beta.quicklisp.org/quicklisp.lisp
sbcl --load quicklisp.lisp \
  --eval "(quicklisp-quickstart:install)" \
  --eval "(ql-dist:install-dist \"http://dist.shirakumo.org/shirakumo.txt\" :prompt nil)" \
  --eval "(ql:add-to-init-file)" \
  --quit
#+END_SRC

*** Step 4: Clone and Setup Project
#+BEGIN_SRC bash
# Clone repository
git clone https://github.com/fade/asteroid /opt/asteroid-radio
cd /opt/asteroid-radio

# Initialize submodules
git submodule update --init

# Create required directories
mkdir -p music/library playlists

# Symlink your music collection (optional)
ln -s /path/to/your/music music/library
#+END_SRC

*** Step 5: Configure PostgreSQL
#+BEGIN_SRC bash
# Create database and user
sudo -u postgres createuser asteroid
sudo -u postgres createdb asteroid
sudo -u postgres psql -c "ALTER USER asteroid WITH PASSWORD 'asteroid_db_2025';"
sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE asteroid TO asteroid;"

# Initialize schema
sudo -u postgres psql -d asteroid -f docker/init-db.sql

# Run migrations
for f in migrations/*.sql; do
  sudo -u postgres psql -d asteroid -f "$f"
done

# Grant permissions
sudo -u postgres psql -d asteroid -c "GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO asteroid;"
sudo -u postgres psql -d asteroid -c "GRANT ALL PRIVILEGES ON ALL SEQUENCES IN SCHEMA public TO asteroid;"
#+END_SRC

*** Step 6: Build the FDK-AAC Shim
The C shim for FDK-AAC must be compiled before building Asteroid. This avoids SBCL signal handler conflicts when calling FDK-AAC directly via CFFI.
#+BEGIN_SRC bash
cd cl-streamer
gcc -shared -fPIC -o libfdkaac-shim.so fdkaac-shim.c -lfdk-aac
cd ..
#+END_SRC

Note: The compiled =libfdkaac-shim.so= is included in the repository. You only need to rebuild it if you update =libfdk-aac=.

*** Step 7: Build and Run
#+BEGIN_SRC bash
# Build the SBCL image
make

# Run
./asteroid
#+END_SRC

On startup, Asteroid will:
1. Start the Radiance web server on port 8080
2. Start the CL-Streamer HTTP server on port 8000
3. Initialise the Harmony audio pipeline with MP3 + AAC encoders
4. Connect to PostgreSQL and load the playlist schedule
5. Resume playback from saved state (if =.playback-state.lisp= exists)
6. Begin streaming audio on =/asteroid.mp3= and =/asteroid.aac=

- *AAC Stream*: http://localhost:8000/asteroid.aac

* Service Configuration

** Systemd Service Setup (Linux)

Create systemd service file:
#+BEGIN_SRC bash
sudo nano /etc/systemd/system/asteroid-radio.service
#+END_SRC

*Service Configuration*:
#+BEGIN_SRC ini
[Unit]
Description=Asteroid Radio Streaming Service
After=network.target postgresql.service
Requires=postgresql.service

[Service]
Type=simple
User=asteroid
Group=asteroid
WorkingDirectory=/opt/asteroid-radio
ExecStart=/opt/asteroid-radio/asteroid
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
#+END_SRC

*** Enable and Start Service
#+BEGIN_SRC bash
# Create service user
sudo useradd -r -s /bin/false asteroid
sudo chown -R asteroid:asteroid /opt/asteroid-radio

# Enable and start service
sudo systemctl daemon-reload
sudo systemctl enable asteroid-radio
sudo systemctl start asteroid-radio
sudo systemctl status asteroid-radio
#+END_SRC

* Network Configuration

** Firewall Setup

*** Ubuntu/Debian (ufw)
#+BEGIN_SRC bash
# Allow required ports
sudo ufw allow 8080/tcp  # Web interface
sudo ufw allow 8000/tcp  # Audio streaming (CL-Streamer)
sudo ufw enable
#+END_SRC

*** CentOS/RHEL (firewalld)
#+BEGIN_SRC bash
sudo firewall-cmd --permanent --add-port=8080/tcp  # Web interface
sudo firewall-cmd --permanent --add-port=8000/tcp  # Audio streaming
sudo firewall-cmd --reload
#+END_SRC

** Reverse Proxy Setup (Optional)

*** Nginx Configuration
#+BEGIN_SRC bash
sudo apt install nginx
sudo nano /etc/nginx/sites-available/asteroid-radio
#+END_SRC

*Nginx Configuration*:
#+BEGIN_SRC nginx
server {
    listen 80;
    server_name your-domain.com;

    # Web interface
    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # Streaming endpoint (CL-Streamer)
    location /stream {
        proxy_pass http://localhost:8000/asteroid.mp3;
        proxy_set_header Host $host;
        proxy_buffering off;
    }
}
#+END_SRC

*** Enable Nginx Site
#+BEGIN_SRC bash
sudo ln -s /etc/nginx/sites-available/asteroid-radio /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
#+END_SRC

** Configuration Files
- =config/radiance-postgres.lisp= - PostgreSQL connection settings

* Troubleshooting

** Common Installation Issues

*** Missing System Libraries
If the build fails with CFFI errors, ensure all dev packages are installed:
#+BEGIN_SRC bash
sudo apt install -y \
  libmp3lame-dev libfdk-aac-dev \
  libflac-dev libmpg123-dev \
  libtag1-dev libfixposix-dev
#+END_SRC

*** FDK-AAC Shim Not Found
If you see "libfdkaac-shim.so not found" during startup:
#+BEGIN_SRC bash
cd cl-streamer
gcc -shared -fPIC -o libfdkaac-shim.so fdkaac-shim.c -lfdk-aac
#+END_SRC

*** Database Connection Errors
- Verify PostgreSQL is running: =sudo systemctl status postgresql=
- Check connection settings in =config/radiance-postgres.lisp=
- Ensure the =asteroid= database exists and the user has permissions
- Run =docker/init-db.sql= and migrations if tables are missing

*** Permission Issues
- Check file ownership and permissions
- Verify service user has access to required directories
- Ensure music directories are readable

*** Stream Not Playing
- Check that the process is running and CL-Streamer started (look for "CL-Streamer started on port 8000" in logs)
- Test stream URLs: =curl -I http://localhost:8000/asteroid.mp3=
- Check for audio file errors in the log (missing files, unsupported formats)
- Verify music library symlink: =ls -la music/library/=

*** SBCL Pathname Issues
File paths containing square brackets (e.g. =[WEB FLAC]=) can cause errors because SBCL's =pathname= function interprets brackets as wildcard patterns. CL-Streamer uses =sb-ext:parse-native-namestring= to avoid this.
